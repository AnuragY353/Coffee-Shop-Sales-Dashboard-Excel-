# ☕ Coffee Shop Sales Dashboard (Excel)

An interactive Microsoft Excel dashboard that visualizes and analyzes sales data of a coffee shop to uncover insights and help drive business decisions.

---

## 📌 Overview

This project aims to provide a comprehensive view of the coffee shop’s sales using Excel’s powerful features. The dashboard presents key performance indicators (KPIs), trends, and visual analytics to support strategic planning for marketing, staffing, and inventory.

---

## 📈 Dashboard Features

- 📅 **Monthly and Daily Sales Trends**
- ☕ **Top-Selling Products**
- 🕒 **Peak Sales Time Analysis**
- 📍 **Location/Branch-wise Performance**
- 👥 **Customer Purchase Behavior**
- 💰 **Total Revenue and Units Sold Overview**

All elements are interactive using:
- Pivot Tables
- Pivot Charts
- Slicers
- Timelines
- Conditional Formatting
